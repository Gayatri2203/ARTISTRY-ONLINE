# 🎨 Artistry Online

Artistry Online is a modern full-stack web application that provides a platform for artists to showcase, manage, and sell their artwork while allowing buyers to discover and purchase unique creations. The platform focuses on creating an engaging marketplace experience with secure authentication, personalized recommendations, and an intuitive user interface.

---

## 📌 Features

### 👩‍🎨 Artist Features
- Artist profile management
- Upload artwork with images
- Edit and delete artworks
- Manage artwork listings
- View personal gallery

### 🛒 Buyer Features
- Browse artworks
- Search and filter by category
- Wishlist functionality
- Like and comment on artworks
- View artwork details

### 🔐 Authentication
- Firebase Authentication
- Login & Registration
- Protected Routes
- User Role Management

### 💬 Communication
- Chat between buyers and artists

### 💳 Shopping
- Shopping Cart
- Checkout Module
- Order Management

### ⭐ Additional Features
- Artwork Recommendation System
- Responsive Design
- Image Upload using Cloudinary
- Form Validation
- Modern Material UI Components
